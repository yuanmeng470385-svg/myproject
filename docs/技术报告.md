# 健康小云 · 技术报告

> AI 健康助手 · 跨平台应用（Flutter Android + Vue 3 Web + FastAPI 后端）

## 一、项目概述

健康小云是一款 AI 健康助手应用，用户可通过**文字对话**、**语音/视频实时通话**向 AI 咨询健康问题，系统自动沉淀**用户画像与长期记忆**，并支持**对话历史管理**。项目同时交付 **Android（Flutter）** 与 **Web（Vue 3）** 两个端，对接统一的 Python FastAPI 后端与阿里云百炼大模型。

- **核心价值**：随时随地的 AI 健康咨询 + 个性化记忆，温和、专业、可追溯。
- **目标平台**：Android（最低 API 21 / Android 5.0）、Web（现代浏览器）。

            ┌──────▼───────┐

            │ auth/consult │
            │ /user/voice  │

        ┌──────────┼───────────┐

- **Flutter 端**采用 Clean Architecture 分层：`core`（基础设施）/ `data`（模型+仓库实现）/ `domain`（仓库接口）/ `presentation`（BLoC + 页面 + 路由）。
- **后端**按 `routers / services / models / schemas / utils` 组织，测试用 SQLite 隔离。

## 四、核心功能

1. **登录/注册**：手机号 + 密码，JWT 鉴权。
2. **AI 文字咨询**：SSE 流式输出，Markdown 渲染，动态快捷问题与跟问建议，支持发送图片（多模态）。
3. **AI 画像与长期记忆**：对话中自动提取事实，去重后写入长期记忆，构建上下文时按重要度注入。
4. **对话历史**：列表、详情、删除、AI 摘要标题（可一键重新生成）。
5. **实时语音/视频通话**：WebSocket 桥接 DashScope Realtime，PCM 音频上下行（16k/24k），server VAD 自动断句、打断，转录持久化并入对话；视频帧（JPEG）上行供多模态识别。
6. **深色模式**：Material Design 3，支持深浅主题切换与持久化。

## 五、跨平台实现要点

### 5.1 Flutter Android
- 平台条件导入（`*_web.dart` / `*_android.dart` / `*_stub.dart`）适配音频录制、播放、摄像头。
- 设计 token 化（颜色/字体/动效/圆角/阴影集中管理），支持深色模式（调色板动态化 + `MaterialApp.builder` 统一重建）。
- 显式 `minSdk = 21`，兼容 Android 5.0 及以上。

## 六、AI 协作开发

全程使用 **Claude / Trae** 辅助开发，遵循"AI 生成 + 人工 review/调整"的协作模式：
- 所有源文件头部均加注释标注 AI 生成与人工修改部分。
- AI 负责整体架构、实现与跨平台移植；开发者负责需求确认、真机测试反馈、问题定位与迭代决策。
- 典型协作案例：深色模式三次方案迭代（调色板动态化 → 规避 `Duplicate GlobalKey`）、语音通话联调（定位 DashScope 限流而非代码问题）。

## 七、关键技术难点

1. **SSE 流式中文截断**：TCP 分块可能在 3 字节 UTF-8 汉字中间切断，导致 JSON 解析失败丢字。解法：累积全部字节，每次对"迄今所有字节"整体解码再按 `\n\n` 解析事件，已结尾事件字节必然完整。
2. **深色模式 GlobalKey 冲突**：给 `MaterialApp`/`AnimatedSwitcher` 换 key 会与 GoRouter 单例 Navigator 的 GlobalKey 冲突。解法：用 `MaterialApp.builder` 的 `KeyedSubtree(isDark)` 重建 Navigator 子树（GlobalKey reparent 而非并存）。
3. **语音通话稳定性**：DashScope Realtime 容量限流（1011）需重试；server VAD 自动断句避免手动 commit 竞态。
